# 여정 내부 디자인 규칙

이 문서는 여정 앱의 **디자인 규칙**을 정리한 문서입니다. 색·타입·간격·컴포넌트 값을 `tokens.json`에 두고, 화면은 이 기준을 따릅니다. 테마는 `Theme.Yeojeong` 하나입니다.

값은 두 층으로 나눠 적용합니다.

- **화면 값**: 이미 만든 화면을 기준에 맞출 때 쓰는 실제 값.
- **기준값**: 새 화면을 만들 때 반복해서 쓸 값.

## 1. 먼저 알아야 할 결론

여정의 시각 언어는 “흰 캔버스 + 선명한 파랑 + 회색 텍스트 + 사진 카드 + 낮은 그림자”입니다. 화면 제목은 크고 검은색이 아니라, 작고 회색인 경우가 많습니다. 검은색 굵은 글씨는 화면 제목보다 **섹션 제목**에 씁니다.

핵심 10개 규칙:

1. 기본 캔버스는 흰색, 설정·마이페이지는 `#F7F7F7` 위에 흰 섹션을 얹습니다.
2. 주 색은 `#0D70FF`입니다. `#0075FF`는 “Coming Soon” 화면의 예외 색입니다.
3. 본문 검정은 `#000000`, 보조 텍스트는 `#727996`, 메타 텍스트는 `#8E8E8E`입니다.
4. 화면 제목은 20dp 전후의 **regular** 회색입니다. 섹션 제목만 20dp bold 검정입니다.
5. 기본 간격 단위는 4dp이고, 화면 좌우와 카드 패딩은 20dp, 섹션 간격은 16dp입니다.
6. 기본 모서리는 8dp, 폼 패널·선택 카드는 16dp, 원형 칩은 56dp입니다.
7. 콘텐츠 카드는 8dp 모서리 + 4dp 그림자 + 흰색 굵은 글씨 + 어두운 그라데이션입니다.
8. 하단 CTA는 높이 56dp, 전체 너비, 16dp bold, 활성 `#0D70FF` / 비활성 `#DCDEE5`입니다.
9. 하단 내비게이션은 56dp, 24dp 아이콘 4개, 라벨 없이 3dp 파란 활성선으로 상태를 표시합니다.
10. 폰트는 시스템 sans-serif입니다. 커스텀 폰트 파일은 없습니다.

### 지하철 노선

`#0052A4` 1호선, `#00A84D` 2호선, `#EF7C1C` 3호선, `#00A5DE` 4호선, `#996CAC` 5호선, `#CD7C2F` 6호선, `#747F00` 7호선, `#E6186C` 8호선, `#BB8336` 9호선.

### 그라데이션

- 이미지 위 오버레이: `#000000` → `#50000000` → `#00000000`.
- 홈 히어로는 왼쪽에서 오른쪽, 카드·리뷰는 아래에서 위로 어두워집니다.
- 버튼·배경에 브랜드 그라데이션은 없습니다.

## 3. 타이포그래피

- 폰트: `sans-serif` 시스템 기본. `res/font` 없음.
- 굵기: regular 400, bold 700만 사용합니다.
- 텍스트 크기는 같은 숫자의 **sp**로 씁니다. 기본 배율에서는 시각이 같고, 사용자 글자 크기 설정을 존중할 수 있습니다.

| 역할 | 크기 | 굵기 | 색 |
|---|---:|---|---|
| MBTI·성별 문자 | 34 | bold | `#DCDEE5` → 선택 시 `#0D70FF` |
| 히어로·북 카드 제목 | 20 | bold | `#FFFFFF` |
| 화면 제목 | 20 | regular | `#727996` |
| 섹션 제목 | 20 | bold | `#000000` |
| 온보딩 제목 | 18 | bold | `#000000` |
| 카드 제목 | 16 | 700 | `#FFFFFF` / `#000000` |
| 보조 본문·탭 | 14~16 | 400 / 700 | `#727996` |
| 캡션·배지 | 12 | 400~700 | `#8E8E8E` / `#FFFFFF` |
| 마이크로 라벨 | 8~10 | bold | 흰색·회색 |

숫자 크기만 보면 계층이 촘촘하지 않습니다. 실제 위계는 **색과 굵기**로 만듭니다. 화면 제목을 검게 굵게 바꾸면 여정의 인상이 크게 달라집니다.

## 4. 간격과 화면 골격

### 기본 간격

| 토큰 | 값 | 사용 |
|---|---:|---|
| base | 4dp | 최소 단위 |
| xs | 8dp | 아이콘·배지·카드 간격 |
| sm | 12dp | 칩·작은 버튼 |
| md | 16dp | 섹션 간격, 목록 상하 |
| lg | 20dp | 화면 좌우, 카드 패딩 |
| xl | 40dp | 폼 블록 사이 |
| nav | 56dp | 헤더·하단 CTA·하단 내비 |
| bottom clearance | 84dp | 스크롤 콘텐츠가 하단 내비를 피하는 여백 |

화면 좌우 여백과 카드 패딩은 20dp가 기준입니다. 섹션 사이는 16dp, 큰 블록 사이는 20~40dp를 씁니다.

### 기본 화면 골격

```
[status bar]
[header: 16dp top/bottom, 20dp start, back 24dp, title]
[content: 20dp start/end, 16~24dp vertical gaps]
[bottom CTA or bottom navigation: 56dp]
```

- 헤더 높이는 약 56dp입니다. 뒤로가기 아이콘은 24dp이고 8dp 패딩을 더해 40dp 터치 영역을 만듭니다.
- 헤더 제목은 20dp regular `#727996`입니다. 설정 화면만 16dp로 작아집니다.
- 홈은 상단 날씨·위치 줄 40dp, 히어로 216dp, 카드 200dp, 하단 내비 56dp를 씁니다.
- 폼 화면은 20dp 여백, 흰 패널 16dp 모서리, 20dp 패딩, 40dp 블록 간격을 씁니다.

## 5. 모서리와 그림자

| 용도 | 반경 | 그림자 |
|---|---:|---:|
| 하단 CTA 바, 설정 섹션, 히어로 | 0dp | 0 |
| 기본 버튼·입력·콘텐츠 카드 | 8dp | 2~4dp |
| 리뷰 작성 카드 | 9dp | 4dp |
| 배지·작은 pill | 12dp | 0 |
| 폼 패널·성별 선택 카드 | 16dp | 10dp |
| 카테고리 pill·북 카드 | 17dp | 4dp |
| 로그인 소셜 버튼 | 22dp | 4dp |
| 원형 프로필·MBTI 칩 | 56/60dp | 0~4dp |

새 화면의 기본값은 **8dp(컨트롤·카드), 16dp(패널), 24dp 이상(원형)**으로 두면 됩니다. 화면별로 맞춰야 할 때만 9·12·17·22dp 예외를 씁니다.

## 6. 컴포넌트 규칙

### 헤더

- 좌우 20dp, 상하 16dp.
- 뒤로가기 24dp + 8dp 패딩.
- 제목 20sp regular `#727996`. 액션이 있으면 오른쪽 24dp.
- 밑줄·그림자 없음.

### 하단 내비게이션

- 높이 56dp, 흰 배경, 4등분.
- 아이콘 24dp, 라벨 없음.
- 활성: 상단 3dp `#0D70FF`, 아이콘 `ic_*_sel`.
- 비활성: 상단 1dp `#DCDEE5`, 아이콘 `ic_*_non`.
- 아이콘만 있으므로 접근성 설명은 반드시 별도로 넣습니다.

### 탭

- 높이 64dp, 텍스트 탭 3개(북마크·리뷰·리포트).
- 16sp bold, 선택 `#000000`, 비선택 `#727996`.
- 기본 Material 인디케이터를 쓰되, 브랜드 블루로 맞춥니다.

### CTA

| 종류 | 규격 |
|---|---|
| 하단 주 CTA | 56dp 높이, 전체 너비, 모서리 0, 16sp bold, 활성 `#0D70FF`/흰색, 비활성 `#DCDEE5`/`#727996` |
| 보조 CTA | 흰 배경, 8dp 모서리, 16sp `#0D70FF`, 상하 8dp, 그림자 2dp |
| 아웃라인 버튼 | 흰 배경, 1dp `#0D70FF` 테두리, 8dp 모서리, 16sp `#0D70FF`, 상하 10dp |

### 입력

- 폼 입력: 흰 배경, 1dp `#727996` 테두리, 8dp 모서리, 8dp 패딩, 14sp `#727996`.
- 검색 입력: `#DCDEE5` 배경, 16dp 모서리, 8dp 패딩, 16sp `#000000`.
- 포커스 테두리는 브랜드 블루로 통일합니다.

### 선택 카드·칩

- 성별 선택: 흰 카드, 16dp 모서리, 2dp `#DCDEE5`, 20dp 패딩, 40dp 상하 여백, 34sp 문자.
- 선택 시 2dp `#0D70FF` 테두리, 문자 `#0D70FF`.
- MBTI: 56dp 원, 2dp 테두리, `#EAECF5` 배경, 34sp 문자. 선택 시 흰 배경 + 파란 테두리.
- 4개 칩 간격은 13.35dp입니다. 320dp 화면에서 넘칠 수 있어 새 화면에서는 8~12dp로 줄이거나 wrap 배치를 권장합니다.

### 이미지 카드

- 모서리 8dp, 그림자 4dp.
- 이미지가 카드 전체를 채우고, 하단 또는 좌측에 검정→투명 그라데이션.
- 제목 16sp bold 흰색, 날짜 14sp 흰색, 큰 제목 24sp bold 흰색.
- 홈 히어로 216dp, 홈 카드 200×200dp, 리뷰 카드 148×148dp, 북 카드 높이 176dp.
- 카테고리 pill은 흰 배경 17dp 모서리, 12sp 검정, 8dp 좌우·4dp 상하 패딩.

### 목록 행

- 흰 배경, 상하 16dp, 시작 20dp, 끝 20dp.
- 텍스트 16sp 검정, 오른쪽 24dp 아이콘.
- 행 사이 1dp `#EAECF5` 구분선.
- 설정은 16dp 간격으로 흰 그룹을 분리합니다.

### 다이얼로그

- 흰 패널, 16dp 모서리, 20dp 패딩, 바깥 8dp 여백.
- 정보 블록은 `#EAECF5` 배경, 16dp 상하·12dp 좌우 패딩.
- 라벨 14sp bold 검정, 설명 14sp `#727996`, 캡션 12sp `#727996`.
- 확인 버튼은 흰 배경 + 1dp 파란 테두리 + 8dp 모서리 + 10dp 상하 패딩.

### 배지·노선 표시

- 이미지 위 배지: `#CC4E4E4E` 12dp 모서리, 흰 글씨, 2×8dp 패딩.
- POP 배지: 흰 배경, 1dp 흰 테두리, 8dp 모서리, 16sp bold 검정.
- 노선 배지: 높이 16dp, 노선 색 배경, 8sp 흰 글씨, 24dp 원형 아이콘 + 18dp 아이콘.

## 7. 화면별 레시피

### 홈

```
20dp 좌우
[위치 pill 40dp][날씨][검색 30dp]
[히어로 216dp, 8dp 모서리, 어두운 오버레이]
[가로 카드 200×200dp, 8dp 간격]
[섹션 제목 16sp black]
[보조 CTA 흰 배경 8dp]
[하단 내비 56dp]
```

### 마이페이지

- 헤더 20dp, 제목 20sp 회색.
- 프로필 80dp 원, 이름 20sp 검정, 칭호 14sp 검정.
- 콜렉션 pill: `#0D70FF`, 8dp 모서리, 12sp 흰색, 12×8dp 패딩.
- 탭 64dp, 하단 내비 56dp.

### 설정

- 배경 `#F7F7F7`, 흰 섹션을 16dp 간격으로 쌓기.
- 행 상하 16dp, 시작 20dp, 끝 20dp.
- 1dp `#EAECF5` 구분선.
- 주의: `#EAECF5`는 흰 배경에서 거의 보이지 않습니다. 이 색을 본문 텍스트에 쓰지 않습니다.

### 폼·온보딩

- 20dp 여백, 제목 20sp bold 검정, 설명 14sp `#727996`.
- 흰 패널 16dp 모서리, 20dp 패딩, 10dp 그림자.
- 블록 사이 24~40dp.
- 하단 CTA 56dp, 전체 너비.

### 장소 상세

- 헤더 20sp 회색, 뒤로가기 24dp.
- 대표 이미지 + 8dp 모서리.
- 액션 아이콘 4개(전화·저장·리뷰·공유)는 24dp, 2dp 그림자.
- 섹션 제목 20sp bold 검정, 본문 14sp `#727996`.
- 리뷰 카드 8dp 모서리, 4dp 그림자, 16sp bold 흰색 제목.

## 8. 엄격 적용 체크리스트

- [ ] 파랑은 `#0D70FF`를 썼는가. `#0075FF`를 새 화면에 쓰지 않았는가.
- [ ] 화면 제목을 검은 bold로 바꾸지 않았는가.
- [ ] 섹션 제목만 20sp bold 검정인가.
- [ ] 화면 좌우 24dp, 섹션 간격 16dp를 지켰는가.
- [ ] 카드 8dp 모서리·4dp 그림자, 패널 16dp 모서리·10dp 그림자를 구분했는가.
- [ ] 하단 CTA가 56dp 전체 너비인가.
- [ ] 하단 내비가 56dp·24dp 아이콘·3dp 활성선인가.
- [ ] 이미지 카드에 어두운 오버레이와 흰색 bold 제목을 넣었는가.
- [ ] 시스템 폰트만 썼는가.
- [ ] 텍스트 크기를 sp로 썼는가.
- [ ] `#EAECF5`·`#DCDEE5`를 본문 텍스트에 쓰지 않았는가.
- [ ] 아이콘 전용 버튼에 contentDescription을 넣었는가.

## 9. 디자인 예외와 주의점

값이 섞여 있는 지점과 접근성에서 주의할 부분입니다.

1. **테마 기본색과 브랜드 색을 분리합니다.** Compose 테마에서 `#0D70FF`를 primary로 고정하고, Switch·CheckBox 같은 기본 컴포넌트도 같은 색을 쓰도록 지정합니다.
2. **상태바 색은 화면마다 직접 지정합니다.** 기본값을 상속하면 흰 화면에서도 파랑이 남습니다.
3. **모서리가 8·9·12·16·17·22·60dp로 섞여 있습니다.** 같은 카드 역할에도 16dp와 17dp가 공존합니다.
4. **좌우 여백이 16·20·24dp로 섞여 있습니다.** 화면은 20dp를 기본으로 두고 목록·검색에서 예외를 둡니다.
5. **텍스트 크기는 sp로 통일합니다.** 사용자 글자 크기 설정을 반영해야 합니다.
6. **대비가 부족한 조합이 있습니다.** `#EAECF5` on white는 1.18:1, `#DCDEE5` on white는 1.34:1입니다. `#727996`은 4.29:1, `#0D70FF`는 4.39:1로 일반 텍스트 AA 기준 4.5:1에 조금 못 미칩니다.
7. **다크 모드 팔레트가 없습니다.** 라이트 모드로 고정하거나 야간 팔레트를 추가합니다.
8. **고정 폭 레이아웃이 있습니다.** MBTI 4칩은 56×4 + 13.35×3 = 264.05dp입니다. 카드 패딩 48dp와 화면 좌우 여백을 더하면 360dp 화면에 겨우 맞고 320dp 화면에서는 넘칩니다. 큰 글자 설정에서도 깨질 수 있습니다.
9. **접근성 터치 영역이 작습니다.** 헤더 아이콘은 24dp + 8dp 패딩 = 40dp로, 권장 48dp보다 작습니다.

## 10. 새 화면에 적용할 기준

화면의 인상을 유지하면서 예외를 줄이려면 다음을 고정값으로 씁니다.

```
color.primary      #0D70FF
color.ink          #000000
color.text.secondary #727996
color.surface      #FFFFFF
color.page         #F7F7F7
color.line         #DCDEE5
color.soft         #EAECF5

type.display       24sp / 700
type.section       20sp / 700
type.screenTitle   20sp / 400 / #727996
type.body          16sp / 400
type.bodySmall     14sp / 400
type.caption       12sp / 400

space.screen       24dp
space.section      16dp
space.block        24dp
space.major        40dp

radius.control     8dp
radius.panel       16dp
radius.circle      999dp

elevation.card     4dp
elevation.panel    10dp
```

이 기준을 “여정 디자인 시스템”으로 고정하고, 화면별로 맞춰야 할 때만 9·12·17·22dp와 20dp 여백을 예외로 허용합니다.
